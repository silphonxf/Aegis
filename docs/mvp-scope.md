# 运维助手 MVP 范围冻结（v1）

## 1. 目标
在最短周期内打通“巡检 + 自检 + 上报 + 查询”的闭环，形成可演示、可试运行版本。

## 2. 角色（MVP）
- **巡检员**：移动端扫码登记、提交巡检记录
- **系统管理员**：执行日检/周检并上报
- **超级管理员**：后台查看全局状态与报表

## 3. MVP 功能清单

### 3.1 账号与权限
- 用户登录（JWT）
- 角色权限控制（RBAC）
- 用户启停状态

### 3.2 巡检（扫码为主，NFC 延后）
- 巡检点二维码识别（先以“扫码结果字符串”录入）
- 记录巡检结果（正常/异常）
- 异常说明与图片附件（附件接口预留）

### 3.3 系统自检
- 日检/周检模板管理（后台）
- 按模板生成自检任务
- 系统管理员提交自检结论（正常/关注/异常）

### 3.4 状态看板（简版）
- 系统状态条目：
  - 主机在线状态
  - 关键端口可达
  - CPU/内存/磁盘阈值结果
  - 最近巡检结论
  - 最近自检结论
- 状态颜色：绿 / 黄 / 红

### 3.5 报表（基础版）
- 巡检记录查询（按系统、时间、结果筛选）
- 自检记录查询（按模板类型、时间、结论筛选）
- CSV 导出

## 4. 暂不纳入 MVP（进入二期）
- NFC 碰触识别
- 抓包工具、远程重启等高危工具
- 离线 AI 诊断引擎（仅保留接口协议）
- 资产批量导入高级校验

## 5. 验收标准（MVP）
1. 完成账号登录与角色权限隔离
2. 移动端可完成扫码巡检并提交
3. 系统管理员可完成日检/周检上报
4. 超级管理员可在后台查看系统状态与报表
5. Docker Compose 一键拉起开发环境
