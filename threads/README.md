# Aegis Threads

Create one folder per independent task or conversation context.

Recommended naming:

```text
YYYY-MM-DD-short-topic
```

Recommended files:

```text
README.md
notes.md
todo.md
handoff.md
```

Template:

```markdown
# Thread Title

## Goal

## Current State

## Key Files

## Decisions

## Next Steps

## Handoff
```
